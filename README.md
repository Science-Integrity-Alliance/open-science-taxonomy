# Open Science Taxonomy

## About the Project
The **Open Science Taxonomy** is a comprehensive classification structure designed to organize the complex and interdisciplinary domain of open science. This taxonomy serves as a reference framework for researchers, publishers, institutions, and policymakers to better understand the theoretical and practical dimensions of the open science movement.

This project offers an interactive implementation of the taxonomy developed by Silveira et al. (2023), which incorporates elements from previously available taxonomies, including the works of Pontika et al. (2015) and UNESCO (2021).

## Key Features:
* **Comprehensive structure**: The taxonomy consists of 10 primary components of open science and 91 subcomponents.
* **Interactive version**: Explore the Open Science Taxonomy in an interactive web interface developed by the Science Integrity Alliance.

## Taxonomy Structure
The Open Science Taxonomy is divided into the following primary components:
1. **Open Access (OA)**
2. **Open Data**
3. **Open Reproducible Research**
4. **Open and Responsible Evaluation**
5. **Policies, Declarations, and Guidelines**
6. **Open Education**
7. **Open Innovation**
8. **Open Infrastructure and Tools**
9. **Citizen Science, Open and Participative**
10. **Open Dialogue with Knowledge Systems**

Each primary component is subdivided into various subcomponents, providing a comprehensive view of the open science landscape.
